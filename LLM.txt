## 2. MODULE SYSTEM

### How Modules Work
Modules are the primary way to extend OTClient functionality. Each module is a directory containing:

1. **`.otmod` file** - Module descriptor (YAML-like format)
2. **`.lua` files** - Lua scripts
3. **`.otui` files** - UI definitions (optional)
4. **Assets** - Images, sounds, etc. (optional)

### Module Descriptor Format (.otmod)
```yaml
Module
  name: game_example           # Unique module name
  description: Example module  # Description
  author: Your Name
  website: https://example.com
  reloadable: true            # Can be hot-reloaded
  sandboxed: true             # Isolated Lua environment
  autoload: true              # Auto-load on startup
  autoload-priority: 500      # Loading order (0-9999)
  
  # Scripts to load (order matters)
  scripts: [ script1, script2, widgets/* ]
  
  # Required modules (loaded first)
  dependencies: [ corelib, gamelib ]
  
  # Modules to load after this one
  load-later:
    - game_console
    - game_battle
  
  # Device restrictions (optional)
  devices:
    - mobile:android
    - desktop:windows
  
  # Lifecycle hooks
  @onLoad: init()             # Called when loaded
  @onUnload: terminate()      # Called when unloaded
```

### Module Loading Sequence
1. `init.lua` starts the application
2. `g_modules.discoverModules()` scans for .otmod files
3. Modules are auto-loaded by priority (0-99 libraries, 100-499 client, 500-999 game)
4. Key modules loaded in order:
   - `corelib` (0-99) - Core Lua utilities
   - `gamelib` (0-99) - Game utilities
   - `modulelib` (0-99) - Module helpers
   - `startup` (0-99) - Startup screen
   - `client` (100-499) - Main client
   - `game_interface` (500-999) - Game UI

### Creating a New Module
1. Create directory: `modules/game_mymodule/`
2. Create `mymodule.otmod`:
```yaml
Module
  name: game_mymodule
  description: My custom module
  author: Me
  sandboxed: true
  scripts: [ mymodule ]
  dependencies: [ corelib, gamelib ]
  @onLoad: init()
  @onUnload: terminate()
```
3. Create `mymodule.lua`:
```lua
-- Global variables
myWindow = nil

function init()
    -- Load UI
    myWindow = g_ui.displayUI('mymodule')
    
    -- Connect to game events
    connect(g_game, {
        onGameStart = onGameStart,
        onGameEnd = onGameEnd
    })
end

function terminate()
    disconnect(g_game, {
        onGameStart = onGameStart,
        onGameEnd = onGameEnd
    })
    
    if myWindow then
        myWindow:destroy()
        myWindow = nil
    end
end

function onGameStart()
    myWindow:show()
end

function onGameEnd()
    myWindow:hide()
end
```

### Controller Pattern (Modern Approach)
```lua
MyController = Controller:new()

function MyController:onInit()
    -- Called once when module loads
    Keybind.new('Windows', 'Toggle MyModule', 'Ctrl+M', '')
    Keybind.bind('Windows', 'Toggle MyModule', {
        { type = KEY_DOWN, callback = function() self:toggle() end }
    })
end

function MyController:onTerminate()
    Keybind.delete('Windows', 'Toggle MyModule')
end

function MyController:onGameStart()
    -- Called when player enters game
    self:registerEvents(g_game, {
        onTeleport = self.onTeleport,
        onDeath = self.onDeath
    })
end

function MyController:onGameEnd()
    -- Called when player leaves game
end
```

### Shader System
Shaders are GLSL fragment shaders applied to map/creatures.

**Shader Types:**
- **Map Shaders**: Applied to entire map view
- **Outfit Shaders**: Applied to creature outfits
- **Mount Shaders**: Applied to mounts

**Creating a Shader (modules/game_shaders/):**
```lua
-- Register shader
g_shaders.createFragmentShader('MyShader', 'shaders/fragment/myshader.frag', false)
g_shaders.addMultiTexture('MyShader', 'images/texture1')
g_shaders.setupMapShader('MyShader')

-- Apply to map
local map = modules.game_interface.getMapPanel()
map:setShader('MyShader')

-- Apply to creature
local player = g_game.getLocalPlayer()
player:setShader('MyShader')
```

**Example Fragment Shader:**
```glsl
// shaders/fragment/grayscale.frag
uniform sampler2D u_Tex0;
varying vec2 v_TexCoord;

void main() {
    vec4 color = texture2D(u_Tex0, v_TexCoord);
    float gray = dot(color.rgb, vec3(0.299, 0.587, 0.114));
    gl_FragColor = vec4(vec3(gray), color.a);
}
```

### WalkController (walk.lua)

```lua
WalkController = Controller:new()

-- Key bindings
local keys = {
    { "Up",      North },
    { "Right",   East },
    { "Down",    South },
    { "Left",    West },
    { "Numpad8", North },
    { "Numpad9", NorthEast },
    -- etc.

-- Walk function
local function walk(dir)
    local player = g_game.getLocalPlayer()
    if not player or g_game.isDead() then return end
    
    if player:isWalkLocked() then return end
    
    -- Pre-walk (client-side prediction)
    if g_game.getFeature(GameAllowPreWalk) then
        local toPos = Position.translatedToDirection(player:getPosition(), dir)
        local toTile = g_map.getTile(toPos)
        if toTile and toTile:isWalkable() then
            player:preWalk(dir)
        end
    end
    
    g_game.walk(dir)
end

    local diagonalMap = {
        [North] = { [West] = NorthWest, [East] = NorthEast },
        [South] = { [West] = SouthWest, [East] = SouthEast },
        -- etc.
    }
    -- Combine directions for diagonal movement
end
```

### Floor Changes
```lua
-- Check if player can change floor
local function canChangeFloor(pos, deltaZ)
    local toPos = {x = pos.x, y = pos.y, z = pos.z + deltaZ}
    local toTile = g_map.getTile(toPos)
    if not toTile then return false end
    
    if deltaZ > 0 then  -- Going DOWN
        return toTile:isWalkable() and (toTile:hasElevation(3) or toTile:hasFloorChange())
    else  -- Going UP
        local fromTile = g_map.getTile(player:getPosition())
        return fromTile and fromTile:hasElevation(3) and toTile:isWalkable()
    end
end
```

## 9. COMMON PATTERNS

### Module Initialization
```lua
-- Standard module pattern
local myWindow = nil

function init()
    myWindow = g_ui.displayUI('myui')
    myWindow:hide()
    
    connect(g_game, {
        onGameStart = show,
        onGameEnd = hide
    })
    
    if g_game.isOnline() then
        show()
    end
end

function terminate()
    disconnect(g_game, {
        onGameStart = show,
        onGameEnd = hide
    })
    
    if myWindow then
        myWindow:destroy()
        myWindow = nil
    end
end

function show()
    myWindow:show()
    myWindow:raise()
    myWindow:focus()
end

function hide()
    myWindow:hide()
end

function toggle()
    if myWindow:isVisible() then
        hide()
    else
        show()
    end
end
```
